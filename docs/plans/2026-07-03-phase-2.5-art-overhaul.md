# Фаза 2.5 «Арт-оверхол» — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Вся кодо-рисованная SVG-графика (сцены, котёнок, цели мини-игр, UI-иконки) заменяется растровыми PNG-ассетами в стиле детской книжной иллюстрации (референсы qwen4/qwen5), которые владелец генерирует в qwen по промптам из арт-брифа; архитектура (спрайты процентами, хотспоты, Reanimated-анимации) сохраняется.

**Architecture:** Ассеты живут в `assets/art/<категория>/<имя>.png` и попадают туда ТОЛЬКО через приёмочный скрипт `scripts/import-art.js` (sharp: удаление белого фона → альфа, обрезка полей, приведение к точному размеру из манифеста `scripts/art-manifest.js`). Статические `require()` собраны в реестрах `src/art/*.ts` — компоненты не знают путей. Сцены остаются слоёными: фон-картинка `resizeMode="cover"` + прозрачные PNG-спрайты процентами с сохранением всех testID и хотспотов. «Живость» — покадровая (бабочка 2 кадра) и трансформы (качание дерева/цветов, дрейф облака, бобы хозяев, поза-поп котёнка). Ошейник котёнка — кодовый SVG-оверлей с якорями по позам (иначе 150 спрайтов вместо 30).

**Tech Stack:** Expo SDK 57, TypeScript, RN `Image`/`ImageBackground` (без новых runtime-зависимостей), react-native-reanimated 4.5 + RN core Animated (декоративные циклы), sharp (только devDependency для приёмки ассетов), Jest + RNTL 14.

**Reference:** спека `docs/specs/2026-07-03-kitten-game-design.md` (§3, §6, §11-риск «симпатичность» — этот план и есть его запасной путь: растровые спрайты при том же коде); план фазы 2 `docs/plans/2026-07-03-phase-2-quests-yard.md`; стиль-референсы владельца `qwen1.png`…`qwen7.png` (корень репо, не коммитить).

- [ ] **Step 5: Реализовать import-art**

`scripts/import-art.js`:

```js
// Приёмка арт-ассета: node scripts/import-art.js <источник.png> <ключ>
// Спрайты: белый фон (связный с краями) -> альфа, обрезка полей, точный размер
// с прозрачными полями (contain). Фоны: точный размер cover.
const fs = require('fs');
const path = require('path');
const sharp = require('sharp');

const { MANIFEST } = require('./art-manifest');

const WHITE_MIN = 235; // r,g,b >= WHITE_MIN считается «белым фоном»

function removeWhiteBackground(data, width, height) {
  // flood fill от всех краевых белых пикселей: внутренние белые детали не трогаем
  const idx = (x, y) => (y * width + x) * 4;
  const isWhite = (i) =>
    data[i] >= WHITE_MIN && data[i + 1] >= WHITE_MIN && data[i + 2] >= WHITE_MIN;
  const visited = new Uint8Array(width * height);
  const queue = [];
  for (let x = 0; x < width; x++) queue.push([x, 0], [x, height - 1]);
  for (let y = 0; y < height; y++) queue.push([0, y], [width - 1, y]);
  while (queue.length > 0) {
    const [x, y] = queue.pop();
    if (x < 0 || y < 0 || x >= width || y >= height) continue;
    const flat = y * width + x;
    if (visited[flat]) continue;
    visited[flat] = 1;
    const i = idx(x, y);
    if (!isWhite(i)) continue;
    data[i + 3] = 0;
    queue.push([x + 1, y], [x - 1, y], [x, y + 1], [x, y - 1]);
  }
}

function opaqueBounds(data, width, height) {
  let minX = width, minY = height, maxX = -1, maxY = -1;
  for (let y = 0; y < height; y++) {
    for (let x = 0; x < width; x++) {
      if (data[(y * width + x) * 4 + 3] > 0) {
        if (x < minX) minX = x;
        if (x > maxX) maxX = x;
        if (y < minY) minY = y;
        if (y > maxY) maxY = y;
      }
    }
  }
  return maxX < 0 ? null : { minX, minY, maxX, maxY };
}

async function processArt(buffer, spec) {
  if (!spec.alpha) {
    return sharp(buffer).resize(spec.width, spec.height, { fit: 'cover' }).png().toBuffer();
  }
  const { data, info } = await sharp(buffer)
    .ensureAlpha()
    .raw()
    .toBuffer({ resolveWithObject: true });
  removeWhiteBackground(data, info.width, info.height);
  const b = opaqueBounds(data, info.width, info.height);
  if (!b) throw new Error('после удаления фона не осталось непрозрачных пикселей');
  return sharp(data, { raw: { width: info.width, height: info.height, channels: 4 } })
    .extract({ left: b.minX, top: b.minY, width: b.maxX - b.minX + 1, height: b.maxY - b.minY + 1 })
    .resize(spec.width, spec.height, {
      fit: 'contain',
      background: { r: 0, g: 0, b: 0, alpha: 0 },
    })
    .png()
    .toBuffer();
}

async function main() {
  const [src, key] = process.argv.slice(2);
  const spec = MANIFEST[key];
  if (!src || !spec) {
    console.error('Использование: node scripts/import-art.js <источник.png> <ключ из art-manifest>');
    process.exit(1);
  }
  const out = path.join(__dirname, '..', 'assets', 'art', `${key}.png`);
  fs.mkdirSync(path.dirname(out), { recursive: true });
  fs.writeFileSync(out, await processArt(fs.readFileSync(src), spec));
  console.log(`OK: ${out} (${spec.width}x${spec.height}, alpha=${spec.alpha})`);
}

if (require.main === module) {
  main().catch((e) => {
    console.error(e.message);
    process.exit(1);
  });
}

module.exports = { processArt };
```

import { useEffect, useRef } from 'react';
import {
  Animated,
  Image,
  StyleSheet,
  View,
  type ImageSourcePropType,
  type ViewStyle,
} from 'react-native';

import { yardArt } from '../art/yardArt';

// Центры интерактивных зон в процентах экрана (архитектура фазы 2 сохранена).
export const YARD_SPOTS = [{ id: 'yard-owner', left: '82%', top: '52%' }] as const;

export type YardSpotId = (typeof YARD_SPOTS)[number]['id'];

const CLOUD_DRIFT_MS = 9_000;
const SWAY_MS = 2_400;
const BOB_MS = 1_800;

// Бесконечный туда-обратно цикл 0..1 (декоративные петли — RN core Animated, как в фазе 2)
function useLoop(durationMs: number) {
  const v = useRef(new Animated.Value(0)).current;
  useEffect(() => {
    const loop = Animated.loop(
      Animated.sequence([
        Animated.timing(v, { toValue: 1, duration: durationMs, useNativeDriver: true }),
        Animated.timing(v, { toValue: 0, duration: durationMs, useNativeDriver: true }),
      ]),
    );
    loop.start();
    return () => loop.stop();
  }, [v, durationMs]);
  return v;
}

function ArtSprite({
  source,
  style,
  testID,
}: {
  source: ImageSourcePropType;
  style: ViewStyle;
  testID: string;
}) {
  return (
    <View style={[styles.sprite, style]} pointerEvents="none">
      <Image source={source} style={styles.fill} resizeMode="contain" testID={testID} />
    </View>
  );
}

// Качающийся у корня спрайт («ВАУ»-слой: дерево и цветы живут на ветру)
function SwaySprite({
  source,
  style,
  testID,
  maxDeg,
  durationMs,
}: {
  source: ImageSourcePropType;
  style: ViewStyle;
  testID: string;
  maxDeg: number;
  durationMs: number;
}) {
  const sway = useLoop(durationMs);
  const rotate = sway.interpolate({
    inputRange: [0, 1],
    outputRange: [`-${maxDeg}deg`, `${maxDeg}deg`],
  });
  return (
    <Animated.View
      style={[styles.sprite, style, { transform: [{ rotate }], transformOrigin: 'bottom center' }]}
      pointerEvents="none"
    >
      <Image source={source} style={styles.fill} resizeMode="contain" testID={testID} />
    </Animated.View>
  );
}

// Сад у загородного дома (спека §3): растровый фон + PNG-спрайты процентами.
export function YardBackground() {
  const drift = useLoop(CLOUD_DRIFT_MS);
  const bob = useLoop(BOB_MS);
  const cloudShift = drift.interpolate({ inputRange: [0, 1], outputRange: [-16, 16] });
  const ownerBob = bob.interpolate({ inputRange: [0, 1], outputRange: [0, -4] });

  return (
    <View style={StyleSheet.absoluteFill} testID="yard-background" pointerEvents="none">
      <Image source={yardArt.bg} style={styles.bg} resizeMode="cover" testID="yard-bg" />
      <Animated.View
        style={[styles.sprite, styles.cloud, { transform: [{ translateX: cloudShift }] }]}
        pointerEvents="none"
      >
        <Image source={yardArt.cloud} style={styles.fill} resizeMode="contain" testID="yard-cloud" />
      </Animated.View>
      <SwaySprite
        source={yardArt.tree}
        style={{ left: '-2%', bottom: '36%', width: '34%', aspectRatio: 700 / 900 }}
        testID="yard-tree"
        maxDeg={1.5}
        durationMs={SWAY_MS}
      />
      <ArtSprite
        source={yardArt.porch}
        style={{ left: '64%', bottom: '38%', width: '34%', aspectRatio: 1 }}
        testID="yard-porch"
      />
      <Animated.View
        style={[
          styles.sprite,
          { left: '76%', bottom: '40%', width: '12%', aspectRatio: 450 / 900 },
          { transform: [{ translateY: ownerBob }] },
        ]}
        pointerEvents="none"
      >
        <Image source={yardArt.owner} style={styles.fill} resizeMode="contain" testID="yard-owner-sprite" />
      </Animated.View>
      {(
        [
          [yardArt.flowerPink, '12%', '10%'],
          [yardArt.flowerBlue, '38%', '6%'],
          [yardArt.flowerOrange, '55%', '12%'],

          key={left}

          testID={`yard-flower-${i}`}
          maxDeg={4}
          durationMs={SWAY_MS + i * 300}
        />
      ))}
    </View>
  );
}

const styles = StyleSheet.create({
  sprite: { position: 'absolute' },
  fill: { width: '100%', height: '100%' },
  bg: { ...StyleSheet.absoluteFillObject, width: undefined, height: undefined },

```tsx
import { useEffect, useRef } from 'react';
import { Animated, Image, StyleSheet, View } from 'react-native';
import Svg, { Circle, Path } from 'react-native-svg';

import { CAT_SPRITES } from '../art/catSprites';
import type { CoatId } from './coats';

export type CatPose = 'idle' | 'happy' | 'sad' | 'eating' | 'sleeping';

export interface CatProps {
  coatId: CoatId;
  collarColor?: string | null;
  pose?: CatPose;
  size?: number;
  animated?: boolean; // пружинка при смене позы
  testID?: string;
}

// Якорь ошейника на спрайте (доли стороны). Подгоняется по арту на чекпоинте.
const COLLAR_ANCHORS: Record<CatPose, { left: number; top: number; width: number; rotate: string }> =
  {
    idle: { left: 0.3, top: 0.56, width: 0.4, rotate: '0deg' },
    happy: { left: 0.3, top: 0.56, width: 0.4, rotate: '0deg' },
    sad: { left: 0.3, top: 0.56, width: 0.4, rotate: '0deg' },
    eating: { left: 0.24, top: 0.62, width: 0.36, rotate: '-14deg' },
    sleeping: { left: 0.34, top: 0.6, width: 0.3, rotate: '8deg' },
  };

export function Cat({
  coatId,
  collarColor = null,
  pose = 'idle',
  size = 160,
  animated = false,
  testID,
}: CatProps) {
  const pop = useRef(new Animated.Value(1)).current;
  const prevPose = useRef(pose);

  // «ВАУ»: смена позы — упругий поп, живее мгновенной подмены картинки
  useEffect(() => {
    if (!animated || prevPose.current === pose) {
      prevPose.current = pose;
      return;
    }
    prevPose.current = pose;
    pop.setValue(0.82);
    Animated.spring(pop, { toValue: 1, friction: 4, useNativeDriver: true }).start();
  }, [pose, animated, pop]);

  const anchor = COLLAR_ANCHORS[pose];

  return (
    <Animated.View
      style={{ width: size, height: size, transform: [{ scale: pop }] }}
      testID={testID ?? `cat-${pose}`}
    >
      {/* мягкая тень на полу — кодом, спрайты без теней (бриф) */}
      <View style={[styles.shadow, { width: size * 0.55, height: size * 0.08 }]} />
      <Image
        source={CAT_SPRITES[coatId][pose]}
        style={styles.sprite}
        resizeMode="contain"
        testID="cat-sprite"
      />
      {collarColor && (
        <View
          testID="cat-collar"
          pointerEvents="none"
          style={{
            position: 'absolute',
            left: anchor.left * size,
            top: anchor.top * size,
            width: anchor.width * size,
            aspectRatio: 2.6,
            transform: [{ rotate: anchor.rotate }],
          }}
        >
          <Svg width="100%" height="100%" viewBox="0 0 52 20">
            <Path d="M2 4 Q26 14 50 4 L50 11 Q26 21 2 11 Z" fill={collarColor} />
            <Circle cx={26} cy={15} r={4} fill="#F5D76E" />
            <Circle cx={26} cy={15} r={4} fill="none" stroke="#C9A227" strokeWidth={1} />
          </Svg>
        </View>
      )}
    </Animated.View>
  );
}

const styles = StyleSheet.create({
  sprite: { width: '100%', height: '100%' },
  shadow: {
    position: 'absolute',
    bottom: 0,
    alignSelf: 'center',
    borderRadius: 999,
    backgroundColor: '#5C4A32',
    opacity: 0.14,
  },
});
```

export function ButterflySprite() {

      resizeMode="contain"

  );
}
