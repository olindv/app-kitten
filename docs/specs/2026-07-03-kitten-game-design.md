# Дизайн-спецификация: «Мой Котёнок» (рабочее название)

Дата: 2026-07-03
Статус: черновик — ожидает утверждения владельцем проекта

## 1. Концепция

Детская игра-питомец для Android (телефоны и планшеты), возраст 5+. Главный герой — котёнок, который живёт с хозяевами в загородном доме. Ребёнок заботится о котёнке, выполняет с ним простые квесты и наблюдает, как котёнок растёт через несколько фаз взросления.

Ключевые принципы (не нарушать ни в одной фиче):

- **Без наказаний.** Котёнок никогда не болеет, не умирает и не «портится». Максимум негатива — грустная мордочка и просьба покушать.
- **Без чтения.** Ребёнок 5 лет может не уметь читать: весь интерфейс строится на иконках, анимациях и звуках. Текст — вспомогательный, для родителей и читающих детей.
- **Крупные цели касания.** Минимум 64dp на интерактивный элемент.
- **Полностью офлайн.** Никакой рекламы, встроенных покупок, ссылок наружу, сбора данных. Это одновременно требование здравого смысла и политики Google Play «Для всей семьи».
- **Простота.** Никаких сложных механик, таймеров давления, ресурсов-валют. Единственный накопитель прогресса — звёзды за квесты.

Язык интерфейса: русский (архитектурно все строки — в одном файле, чтобы позже добавить локализации).

## 2. Создание котёнка

Первый запуск открывает экран создания:

1. **Окрас** — карусель из 6 вариантов: рыжий, серый, чёрно-белый, полосатый (табби), белый, сиамский. Реализуется палитрами цветов поверх одного SVG-шаблона котёнка.
2. **Аксессуар** — ошейник одного из 4 цветов (или без него).
3. **Имя** — поле ввода + кнопка «🎲 случайное имя» (пул из ~20 имён: Мурзик, Барсик, Пушинка, …). Имя может быть пустым — тогда подставляется случайное.

Профиль сохраняется локально. Кнопка «начать заново» спрятана в настройках (с подтверждением удержанием — защита от случайного сброса ребёнком).

## 3. Мир игры: сцены

Две сцены, переключение стрелками по краям экрана:

- **Дом** — гостиная с кухонным уголком: миска, лежанка, когтеточка, клубок, коробка, диван, окно, хозяева (стилизованные фигуры на диване/у плиты).
- **Двор** — сад у загородного дома: трава, забор, дерево, цветы, крыльцо. Здесь появляются мышки, бабочки, птички, ёжик, светлячки (вечером).

Сцены — статичные SVG-фоны с интерактивными SVG-объектами поверх. Котёнок присутствует в текущей сцене; тап по объекту запускает действие или мини-игру. Тап по самому котёнку — мурлыканье и анимация ласки (сердечки).

Время суток: декоративная смена (день/вечер) по реальным часам устройства; вечером во дворе светлячки. Никакой привязки «котёнок спит ночью и недоступен» — играть можно всегда.

## 4. Потребности котёнка

Три мягкие шкалы 0–100, отображаются иконками в углу экрана (рыбка / молния / сердечко):

| Потребность | Падение                                                                              | Как пополнить                                               |
| ----------- | ------------------------------------------------------------------------------------ | ----------------------------------------------------------- |
| Сытость     | ~1 пункт / 15 мин реального времени, считается по разнице времени при входе, пол — 0 | Покормить (миска / попросить у хозяев), попить молочка      |
| Энергия     | тратится на мини-играх                                                               | Поспать в лежанке (короткая анимация ~10 сек, не блокирует) |
| Настроение  | медленно падает без игр                                                              | Любая игра, поглаживание, выполнение квеста                 |

Когда сытость < 30, котёнок **сам просит кушать**: подходит к хозяину или миске, над головой появляется облачко с рыбкой, звучит просящее «мяу». Ребёнок тапает по хозяину — хозяин наполняет миску, котёнок ест (анимация + звук), сытость восстанавливается. Это ключевая сценка игры и она же — квест №5.

При любых значениях шкал вся функциональность доступна — шкалы влияют только на позу/мордочку котёнка и подсказки.

## 5. Фазы роста

| Фаза | Название    | Условие перехода               | Визуально                                |
| ---- | ----------- | ------------------------------ | ---------------------------------------- |
| 1    | Малыш       | старт                          | маленький, большая голова, короткие лапы |
| 2    | Подросток   | 10 звёзд И минимум 2 дня игры  | средний размер                           |
| 3    | Молодой кот | 25 звёзд И минимум 5 дней игры | взрослые пропорции, пышный хвост         |

«День игры» — календарный день, в который приложение открывали. Переход сопровождается праздничной сценкой (конфетти, фанфары, хозяева радуются). Рост не открывает и не закрывает контент — меняется только внешний вид и часть анимаций. Возможность регресса отсутствует.

После фазы 3 игра продолжается бесконечно: квесты можно перепроходить, звёзды копятся в «альбом достижений».

## 6. Квесты

Квесты выдаются по 3 активных одновременно, отображаются в журнале (кнопка 📜) картинками. Выполненный квест даёт 1–3 звезды, проигрывается фейерверк-поощрение. Квесты перевыдаются циклически, часть привязана к сцене.

| #   | Квест                             | Сцена        | Механика                                                                                | Звёзды |
| --- | --------------------------------- | ------------ | --------------------------------------------------------------------------------------- | ------ |
| 1   | Поймай 3 мышек и принеси хозяевам | Двор         | мини-игра «поймай тапом»: мышки перебегают, тап = поймал; потом тап по хозяину — отдать | 3      |
| 2   | Поймай 5 бабочек                  | Двор         | «поймай тапом», бабочки порхают по кривым                                               | 2      |
| 3   | Поиграй с клубком                 | Дом          | тапы/свайпы по клубку — он катается, разматывается                                      | 1      |
| 4   | Поточи коготки                    | Дом          | 5 быстрых тапов по когтеточке — полоска прогресса из царапок                            | 1      |
| 5   | Попроси еду у хозяев и покушай    | Дом          | сценка «просит кушать» (см. §4)                                                         | 1      |
| 6   | Найди спрятанную игрушку          | Дом          | мышка-игрушка прячется за одним из предметов, искать тапами                             | 2      |
| 7   | Погоняй воробья                   | Двор         | воробей прыгает по земле, тап рядом — вспорхнул, 3 раза                                 | 1      |
| 8   | Поспи в лежанке                   | Дом          | тап по лежанке — анимация сна с «Z-z-z»                                                 | 1      |
| 9   | Умойся лапкой                     | Дом/Двор     | круговой свайп по котёнку — умывается                                                   | 1      |
| 10  | Попей молочка                     | Дом          | тап по блюдцу — лакает                                                                  | 1      |
| 11  | Поймай солнечного зайчика         | Дом          | световое пятно бегает по полу, 3 тапа                                                   | 2      |
| 12  | Спрячься в коробке                | Дом          | тап по коробке — прыжок внутрь, торчат ушки                                             | 1      |
| 13  | Познакомься с ёжиком              | Двор         | ёжик выходит из-под куста, тап — обнюхались, сердечко                                   | 2      |
| 14  | Поймай светлячков                 | Двор (вечер) | «поймай тапом» светящихся точек; днём квест заменяется другим                           | 2      |
| 15  | Принеси тапочек хозяину           | Дом          | перетащить тапочек к хозяину пальцем (drag)                                             | 2      |

Мини-игровых шаблона всего три (переиспользуются): **поймай-тапом** (движущиеся цели), **найди-предмет**, **повтори-жест** (тапы/свайп по месту). Никаких таймеров на проигрыш — мини-игра всегда заканчивается победой, вопрос только времени.

## 7. Экраны приложения

1. **Сплэш** → проверка сохранения.
2. **Создание котёнка** (только если нет сохранения).
3. **Игровая сцена** (Дом/Двор) — главный экран, 95 % времени.
4. **Журнал квестов** — модальное окно с картинками активных квестов и прогрессом.
5. **Альбом достижений** — звёзды, фаза роста, выполненные квесты.
6. **Настройки** — звук вкл/выкл, музыка вкл/выкл, сброс игры (удержание 3 сек).

## 8. Технический стек

| Слой      | Выбор                                                              | Обоснование                                                                                                                                                                |
| --------- | ------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Фреймворк | **React Native через Expo (последний стабильный SDK), TypeScript** | Expo — это RN с батарейками: звук, сплэш, иконки, сборка `npx expo run:android` через установленный Android Studio SDK. Release-APK собирается локально Gradle, без облака |
| Навигация | React Navigation (native-stack)                                    | 3 экрана + модалки, стандарт де-факто                                                                                                                                      |
| Состояние | Zustand + persist в AsyncStorage                                   | Маленький стейт, простая модель, персист из коробки                                                                                                                        |
| Графика   | react-native-svg — вся графика кодом                               | Окрасы = палитры, фазы роста = параметры пропорций, масштаб на планшеты бесплатно                                                                                          |
| Анимации  | react-native-reanimated                                            | Движение целей мини-игр, анимации котёнка, жесты через react-native-gesture-handler                                                                                        |
| Звук      | expo-audio                                                         | Мяу, мурлыканье, фанфары, фоновая музыка; все звуки — локальные ассеты (CC0)                                                                                               |
| Тесты     | Jest + @testing-library/react-native                               | Юнит-тесты логики (потребности, квесты, рост); UI — ручная проверка на устройстве                                                                                          |

Альтернатива, рассмотренная и отклонённая: «голый» RN через `@react-native-community/cli` — больше ручной настройки (звук, иконки, сплэш) без выгод для этого проекта. Игровой движок (Skia/game-engine) не нужен: три шаблона мини-игр покрываются Reanimated.

Требования к устройствам: Android 8+ (minSdk 26), телефоны и планшеты, портретная и альбомная ориентация (сцены адаптивные, safe area учитывается).

## 9. Архитектура кода

```
src/
  app/            # навигация, корневые провайдеры
  screens/        # CreateCat, GameScene, QuestJournal, Achievements, Settings
  scenes/         # Дом, Двор: фон + раскладка интерактивных объектов
  cat/            # SVG-котёнок: шаблон, палитры окрасов, пропорции фаз, анимации
  quests/         # реестр квестов (данные), движок квестов (логика)
  minigames/      # catch-tap, find-hidden, gesture-repeat
  needs/          # модель потребностей, тики по времени
  store/          # zustand-сторы: profile, progress, needs, settings
  audio/          # менеджер звука
  ui/             # общие компоненты: IconButton, StarBar, Bubble
  i18n/           # strings.ru.ts
assets/           # звуки, шрифт
docs/             # спеки и планы
```

Ключевые инварианты:

- **Квесты — данные, не код.** Реестр квестов описывает: id, сцена, тип мини-игры, параметры, награда, иконка. Движок один. Новый квест = новая запись + при необходимости параметры.
- **Котёнок — один компонент** `<Cat phase coat pose />`; ни одна сцена не знает, как он устроен внутри.
- **Вся запись прогресса — через сторы**, компоненты не пишут в AsyncStorage напрямую.
- **Время** берётся через единый модуль `clock` (инъекция для тестов пересчёта сытости и «дней игры»).

Модель данных (persist):

```ts
profile:  { name: string; coatId: CoatId; collarColor: string | null }
progress: { stars: number; phase: 1|2|3; playDays: string[];        // ISO-даты
            activeQuests: QuestState[]; completedLog: QuestLogEntry[] }
needs:    { hunger: number; energy: number; mood: number; updatedAt: number }
settings: { soundOn: boolean; musicOn: boolean }
```

Обработка ошибок: повреждённое сохранение → мягкий сброс на экран создания (без краша); все звуки не критичны — сбой загрузки звука игнорируется.

## 11. Риски

- **SVG-производительность на слабых устройствах** — держим сцены < ~60 узлов SVG, анимации только через Reanimated (UI-поток); проверка на реальном устройстве в фазе 1, а не в конце.
- **Симпатичность рисованного кодом котёнка** — прототип котёнка показывается владельцу проекта в начале фазы 1; при неудаче запасной путь: заказ/генерация растровых спрайтов при том же коде (меняется только внутренность `<Cat/>`).
- **Звуковые ассеты** — только CC0-источники (freesound.org и аналоги), лицензии фиксируются в `assets/CREDITS.md`.
